Hướng dẫn nhập vào Microsoft Project
Work: Resource Sheet → Type = Work → nhập Std. Rate (₫/h) → gán vào task → MS Project tự tính = Rate × Duration × Units
Material: Type = Material → nhập Unit (chiếc/tháng/license) → nhập Std. Rate (₫/unit) → khi gán task nhập số lượng
Cost: Type = Cost → KHÔNG nhập Rate tại Resource Sheet → gán vào task → nhập trực tiếp số tiền trong cột Cost ở Task → chọn Accrue (Start/End/Prorated)
Accrual: Start = trả trước (domain, SSL, license); Prorated = phân đều theo thời gian (cloud, lương); End = trả sau khi hoàn thành (pentest, audit)
